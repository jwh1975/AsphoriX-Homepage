02 · Problem → Solution

중·대구경 비구면 광학의
구조적 한계를 공정으로 풉니다.

고난도 비구면 광학부품은 프로젝트 단위로 한 점씩 만들어져 왔습니다. 납기·비용·수율·조달의 네 가지 병목은 장인의 문제가 아니라 공정 구조의 문제이며, 애스포릭스는 이를 측정 데이터가 다음 가공을 결정하는 폐루프 구조로 해결합니다.

Problem 01

긴 납기 · 높은 비용 · 낮은 수율

가공 → 탈착·이송 → 측정 → 전문가 판단 → 재가공의 분절 공정. 고난도 프로젝트는 수개월 단위 납기와 반복 재작업이 일상입니다.

→
Solution 01

AI 폐루프 공정제어로 반복 횟수 최소화

잔류오차를 실시간 학습해 최적 연마 궤적을 자율 산출합니다. 리드타임 70% 단축, First-Pass Yield 95% 이상을 검증 목표로 설정했습니다.

Problem 02

ITAR 등 수출통제로 인한 글로벌 조달 제약

고사양 광학부품은 품목·기술·최종용도별 통제 대상이 되어, 글로벌 우주·방산 고객이 안정적인 대체 공급처를 찾기 어렵습니다.

→
Solution 02

ITAR 의존도를 최소화한 컴플라이언스 기반 공급

국내·우방국 기술과 자체 알고리즘으로 기술자료 원천을 구성하고, 거래별 수출통제 검토를 전제로 글로벌 고객에 공급합니다.

Problem 03

프로젝트 단건 생산의 한계

동일 사양의 부품을 여러 개 만들어도 매번 다른 결과가 나옵니다. 장인 1:1 수공 구조에서는 대량·반복 생산이 성립하지 않습니다.

→
Solution 03

지능형 다품종 양산 체계

측정·가공 데이터 레이크와 로봇 자동 핸들링을 결합한 자동화 셀을 라인과 팩토리 단위로 복제합니다. 사람이 아니라 시스템을 늘립니다.

03 · Core Technology

가공–측정–AI 보정을 잇는
AI Closed-Loop 공정제어

측정 결과는 검사 성적표가 아니라 다음 가공 조건을 결정하는 입력값입니다. 애스포릭스의 자체 소프트웨어는 이종 계측 데이터를 단일 좌표계로 정합하고, 잔류오차를 학습해 공정 Recipe를 자동으로 갱신합니다. 목표 정밀도에 도달할 때까지 측정과 가공이 무인으로 반복됩니다.

CLOSED-LOOP PROCESS // ASX-CLPMEASURE → LEARN → CORRECT → REPEAT
TECH-01

측정 데이터 퓨전

이종 4종 계측기의 데이터를 단일 좌표계로 정합·융합하는 자체 소프트웨어. 마이크로미터급 형상부터 나노미터급 파면·조도까지 하나의 오차 지도로 만듭니다.

TECH-02

AI 보정 엔진

소재·공구별 TIF(공구영향함수)와 잔류오차를 학습해 보정량을 산출합니다. 실험 데이터 기반 결정론적 연마 지표 예측 연구(Optics Express, 2026)를 공정에 적용합니다.

TECH-03

Recipe 자동화 · SPC

공정 Recipe와 Tool Path를 자동 산출·갱신하고, 통계적 공정관리(SPC) 기반 품질 예측 모델로 변동성을 최소화합니다. 축적될수록 따라오기 어려운 데이터 해자가 됩니다.

TECH-04

지능형 자동화 라인

가공 셀·측정 스테이션·데이터 레이크·로봇 핸들링을 하나의 라인으로 통합합니다. 검증된 셀 구조를 라인과 팩토리로 복제하는 확장 가능한 설비 아키텍처입니다.
